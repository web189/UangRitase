# v36 — Hitung mundur hanya untuk periode berjalan & sudah ada input
- Kartu hitung mundur tampil hanya jika: periode sudah berjalan (bukan tanggal depan), belum terkunci, dan sudah ada minimal 1 baris input.
- Otomatis muncul begitu baris pertama dicatat; hilang lagi bila semua baris dihapus.
- Tanggal depan: tanpa kartu. Kunci otomatis 08.30 tetap berlaku di belakang layar.
- Tetap tampil: kartu "Terkunci" (agar admin bisa buka kunci) dan kartu "Dibuka admin 3 menit".
